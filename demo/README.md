Demo: synthetic before/after example

Larkspur Row Advisory is a fictional firm. before.md is a made-up post seeded with failures from the catalog. after.md is a revised draft with bracketed placeholders where real facts would go.

before.output.md and after.output.md are the checker's output for each draft, from one run each, shown as returned. RUN.md has the exact command and model.

Read these limits first:
- One run per draft. Repeated runs can return different flags. The test set in tests/ measures that variation; this demo does not.
- The after draft has placeholders, so the checker could not evaluate its figures, dates or award details. Its one flag is on a placeholder line and is not a statement about those facts.
- Fewer flags is not a clearance. The checker covers documented failures only. Every output ends with: "Pre-review only. Not legal or compliance advice. Confirm with your CCO or counsel."
- These are demonstration runs, not scored test runs.
